# Cloud Kitchen PNL Dashboard

## Project Overview

This project analyzes Profit & Loss (PNL) data for cloud kitchen stores across different cities and months.

The analysis focuses on:
- Kitchen-level profitability
- Revenue trends
- EBITDA analysis
- Contribution Margin (CM)
- Variance/Wastage analysis
- Revenue cohort analysis

The dashboard is developed using:
- Python
- Streamlit
- Plotly
- Pandas

---

## Features

### Dashboard 1 – Kitchen Level PNL
- Store-wise analysis
- Revenue trends
- EBITDA analysis
- CM% and GM% analysis
- Interactive filters

### Dashboard 2 – Variance Level PNL
- Variance bucket analysis
- Revenue cohort analysis
- Store count heatmap
- Monthly store performance tracking

---

## Technologies Used

- Python 3.11
- Pandas
- NumPy
- Plotly
- Streamlit
- OpenPyXL
